# Текст Священного Писания

`synodal.json` — полный Синодальный перевод (77 книг, включая неканонические:
Товит, Иудифь, Премудрость Соломона, Сирах, Послание Иеремии, Варух,
1–3 Маккавейские, 2–3 Ездры), 37 086 стихов.

Структура: `{"Быт": {"1": {"1": "В начале сотворил Бог небо и землю.", …}, …}, …}`.
Ключи книг — сокращения, принятые в приложении (Быт, Притч, Прем, Мф, 1Кор …;
Послание Иеремии — `ПослИер`). Курсив Синодального перевода (слова, добавленные
переводчиками) сохранён тегами `<i>…</i>`; вставки из Септуагинты — в квадратных
скобках, как в печатном издании.

## Источник и лицензия

Текст Синодального перевода (1876) — общественное достояние. Цифровое издание
взято из проекта **Ponomar** (https://github.com/typiconman/ponomar,
`Ponomar/languages/cu/ru/bible/synod`), который распространяется по лицензии
GNU GPL 3.0 — её текст в файле `LICENSE-GPL-3.0`.

Пересобрать файл: `python tools/convert_ponomar_bible.py <папка synod> data/bible/synodal.json`.
