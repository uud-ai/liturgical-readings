# Чтения дня (Евангелие и Апостол по зачалам)

Мини-приложение на Python, которое по дате выводит положенные на этот день
евангельское и апостольское зачала согласно богослужебному уставу Русской
Православной Церкви.

## Статус проекта

**Подвижный круг реализован почти целиком:**

- рядовые чтения от Пасхи до Недели о мытаре и фарисее — Апостол и Евангелие
  на каждый день (седмицы 1–33 по Пятидесятнице);
- **Триодь постная** (`data/triodion.json`) — от Недели о мытаре до Великой
  Субботы: литургийные чтения, паремии 6-го часа и вечерни великопостных
  будней, заупокойные чтения родительских суббот, чтения святых воскресений
  поста, Страстная седмица (12 Евангелий Страстей, Царские часы, составные
  Евангелия, 15 паремий Великой Субботы); в будни поста — пометка, совершается
  ли Литургия Преждеосвященных Даров;
- воскресные утренние Евангелия (11-недельный цикл от Пятидесятницы до
  Недели 5-й поста).

Не реализованы период от Недели святых отец перед Рождеством до Недели о
Закхее и праздничные/святые чтения по Минее — в эти дни приложение прямо
об этом сообщает и даёт ссылку на чтения дня на «Азбуке веры».

**Полный текст Библии** (Синодальный перевод, 77 книг с неканоническими —
`data/bible/`): каждое чтение раскрывается прямо в приложении, с номерами
стихов и курсивом Синодального перевода; все 922 ссылки приложения проверены
тестом на полноту текста.

Веб-интерфейс (`app.py`): дата по старому и новому стилю, переход на соседние
дни, раскрывающийся текст каждого чтения (кнопка «Раскрыть все тексты»),
ссылка на чтение на azbyka.ru, светлая и тёмная тема.

## Идея устройства

Богослужебный год чтений построен не по гражданским датам, а по седмицам
(неделям), отсчитываемым от Пасхи и от Пятидесятницы, плюс отдельный слой
неподвижных (праздничных и святых) чтений — этот слой пока сознательно
не реализован.

Реализованная логика (`src/cycle.py`):

1. Дата Пасхи берётся из `data/pascha_dates.json`, а для отсутствующих там
   лет вычисляется по юлианской пасхалии (+13 дней, 1900–2099 гг.).
2. От Пасхи — «седмица N, день недели»: Пятидесятница = Пасха + 49 дней,
   Неделя N по Пятидесятнице = Пятидесятница + 7N дней.
3. **Апостол** читается по счёту седмиц от Пятидесятницы.
4. **Евангелие** с понедельника после Недели по Воздвижении читается от
   Луки, начиная с рядового чтения 18-й седмицы (Лк 3:19–22, зач. 10), —
   Воздвиженская отступка/преступка. Поэтому Апостол и Евангелие одного дня
   могут браться из разных седмиц таблицы.
5. С Недели о Закхее (за 77 дней до Пасхи) чтения считаются назад от
   следующей Пасхи: Неделя о Закхее — 32-я, будни после неё — 33-я седмица.
6. Воскресные утренние Евангелия по Пятидесятнице вычисляются по 11-недельному
   циклу (Неделя Всех святых — 1-е).
7. С Недели о мытаре и фарисее до Великой Субботы чтения берутся из
   `data/triodion.json` по числу дней до Пасхи (70 … 1).
8. **Не реализовано** (приложение прямо сообщает об этом, а не показывает
   догадку): период от Недели святых отец перед Рождеством до Недели о
   Закхее (рождественская и крещенская отступки), праздничные и святые
   чтения. Для воскресений, когда
   устав заменяет рядовые чтения (пред и по Воздвижении, праотец), выводится
   предупреждение.

## Структура данных

```
data/
  pascha_dates.json       # известные даты Пасхи по годам (не вычисляем сами)
  ordinary_cycle.json     # рядовые чтения по седмицам (от Пасхи / Пятидесятницы)
  triodion.json           # Триодь постная: чтения по службам, ключ — дней до Пасхи
  feasts.json             # праздники, особые дни, памяти святых (ключ — дата ст. ст.)
  bible/synodal.json      # Синодальный перевод (источник и лицензия — bible/README.md)
  gospel_zachala.json     # отдельные проверенные тексты-примеры зачал
  apostle_zachala.json    # отдельные проверенные тексты-примеры зачал
src/
  links.py                # ссылки на текст чтений и на день на azbyka.ru
  bible_text.py           # разбор ссылки «Мф.4:25-5:12» и текст стихов
  cycle.py                # дата -> седмица/день для Апостола и для Евангелия
  readings.py             # позиция в круге -> чтение дня
tests/test_readings.py    # проверки по контрольным датам
main.py                   # CLI: python main.py [ГГГГ-ММ-ДД]
app.py                    # веб-интерфейс (Flask)
parser.py                 # вспомогательная загрузка текстов зачал (azbyka.ru)
```

### `gospel_zachala.json`

Евангелие имеет отдельный счёт зачал для каждого евангелиста:
Мф. — 1–116, Мк. — 1–71, Лк. — 1–114, Ин. — 1–67.

```json
{
  "Мф": {
    "116": {"ref": "Мф. 28:16–20", "text": "..."}
  }
}
```

### `apostle_zachala.json`

Апостол (Деяния и все Послания) имеет один сквозной счёт зачал, всего 335.

```json
{
  "1": {"ref": "Деян. 1:1–8", "book": "Деяния", "text": "..."}
}
```

### `ordinary_cycle.json`

```json
{
  "pentecost_period": {
    "13": {
      "mon": {"apostle": "2Кор.8:7-15", "gospel": "Мк.3:6-12"},
      "sun": {"apostle": "1Кор.16:13-24", "gospel": "Мф.21:33-42", "note": "..."}
    }
  }
}
```

Ключ `N` — это «моя» седмица: блок будних дней (mon..sat) плюс воскресенье
(sun), которым он заканчивается. `gospel_zachalo`/`apostle_zachalo` —
традиционный номер зачала, если он проверен по указателю чтений или по
лекционариям orthocal/Ponomar (не для всех записей есть).

## Источники данных

Тексты синодального перевода Евангелия и Апостола — общественное достояние
(перевод 1876 г.), их можно свободно использовать. Сложность не в правах,
а в том, что:

- Полная годовая таблица зачал по датам с учётом всех исключений устава
  публикуется в специализированных изданиях («Богослужебные указания») и на
  нескольких церковных порталах (например, azbyka.ru — раздел «Церковный
  календарь»), но эти сайты закрыты для автоматического скрапинга
  (бот-защита), а домен не входит в список разрешённых для сетевого доступа
  в этой рабочей среде — поэтому их нельзя было обойти скриптом целиком.
- То, что удалось собрать в `ordinary_cycle.json` — результат точечных
  запросов через обычный веб-поиск (см. поле `source`/цитируемые названия
  страниц у части записей), с перепроверкой, где это было можно. Это
  реальный, но неполный и трудоёмкий процесс: полное покрытие всех ~50
  седмиц годового круга потребует ещё многих таких запросов.
- Праздничные и святые чтения (которые в реальном уставе часто заменяют
  рядовые) сознательно не собираются — по вашему решению ограничиться
  рядовым кругом.

## Сверка с авторитетными источниками (25.10.2026)

Таблица `ordinary_cycle.json` сверена построчно с двумя открытыми
лекционариями — [orthocal](https://github.com/brianglass/orthocal-python)
(полная таблица чтений по дням от Пасхи с номерами зачал) и
[Ponomar](https://github.com/typiconman/ponomar) (русская практика,
славянская нумерация стихов), а контрольные даты — с
[azbyka.ru](https://azbyka.ru/biblia/days/2026-10-25). Исправлены ошибочные
ссылки, заполнены пропуски, проставлены номера зачал. Недостававшие будние
дни (290 чтений) взяты из Ponomar (славянская нумерация стихов) и каждое
подтверждено по номеру зачала лекционарием orthocal; такие записи помечены
полем `source`. Половинные стихи (у Ponomar «3b», «12a») округлены до
целого стиха. Оставшиеся пять
расхождений с orthocal (Еф 5:9–19, Мк 3:20–27, 2Кор 13:3–13 и др.) — разница
русской и западной нумерации стихов, для русского текста верны.

Триодь постная собрана из Ponomar (русская практика) со сверкой по orthocal
и выборочно по azbyka.ru (01.02, 14.02, 08.03, 17.03, 06.04, 09.04, 10.04,
11.04.2026). Составное Евангелие вечерни Великой Пятницы дополнено частью
Мф 27:55–61, пропущенной в Ponomar.

## Использование

```bash
python main.py                # чтения на сегодня
python main.py 2026-09-14     # чтения на конкретную дату (ГГГГ-ММ-ДД)
python main.py 2026-09-14 --text   # то же с полным текстом чтений
python -m unittest discover tests   # проверки
```

Если данных для конкретной седмицы ещё нет, скрипт честно об этом сообщает,
а не выдаёт правдоподобную, но непроверенную ссылку.
