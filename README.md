# Чтения дня (Евангелие и Апостол по зачалам)

Мини-приложение на Python, которое по дате выводит положенные на этот день
евангельское и апостольское зачала согласно богослужебному уставу Русской
Православной Церкви.

## Статус проекта

**Каркас готов, данные — нет.** Это первая версия структуры проекта.
Реального массива чтений на весь год пока нет: он должен быть либо
подготовлен из надёжного источника, либо загружен пользователем. См. раздел
«Источники данных» ниже — там же объяснено, почему это нетривиальная задача.

## Идея устройства

Богослужебный год чтений построен не по гражданским датам, а по седмицам
(неделям), отсчитываемым от Пасхи, плюс отдельный слой неподвижных
(непереходящих) праздничных и святых чтений, привязанных к числам месяца.
Поэтому для конкретного года (2026/2027) нужно:

1. Знать дату Пасхи в этом году (её не вычисляем сами — берём из
   уже опубликованного, проверяемого источника).
2. Иметь таблицу «седмица/день недели → зачало» (рядовые, обычные чтения).
3. Наложить на неё исключения: двунадесятые и великие праздники, дни памяти
   святых с особыми чтениями, попразднства, отступки/преступки и т.п.
   (это самая сложная часть устава).
4. Иметь сами тексты зачал (Евангелие и Апостол), разбитые по номерам.

## Структура данных

```
data/
  gospel_zachala.json     # тексты евангельских зачал по Евангелистам
  apostle_zachala.json    # тексты апостольских зачал (сквозная нумерация 1–335)
  readings_calendar.json  # дата → {евангельское зачало, апостольское зачало}
src/
  readings.py             # загрузка данных и получение чтения на дату
main.py                   # CLI: python main.py [ГГГГ-ММ-ДД]
```

### `gospel_zachala.json`

Евангелие имеет отдельный счёт зачал для каждого евангелиста:
Мф. — 1–116, Мк. — 1–71, Лк. — 1–114, Ин. — 1–67.

```json
{
  "Мф": {
    "116": {"ref": "Мф. 28:16–20", "text": "..."}
  }
}
```

### `apostle_zachala.json`

Апостол (Деяния и все Послания) имеет один сквозной счёт зачал, всего 335.

```json
{
  "1": {"ref": "Деян. 1:1–8", "book": "Деяния", "text": "..."}
}
```

### `readings_calendar.json`

```json
{
  "2026-09-14": {
    "gospel": {"book": "Мф", "number": 116},
    "apostle": {"number": 1},
    "note": "пример записи, не проверено"
  }
}
```

## Источники данных

Тексты синодального перевода Евангелия и Апостола — общественное достояние
(перевод 1876 г.), их можно свободно использовать. Сложность не в правах,
а в том, что:

- Полная годовая таблица зачал по датам с учётом всех исключений устава
  публикуется в специализированных изданиях («Богослужебные указания» —
  ежегодное издание, обычно Донского/Сретенского монастыря или Издательства
  Московской Патриархии) и на нескольких церковных порталах (например,
  azbyka.ru — раздел «Церковный календарь»), но эти сайты закрыты для
  автоматического скрапинга (бот-защита), а домен не входит в список
  разрешённых для сетевого доступа в этой рабочей среде.
- «Рядовая» (обычная, без праздничных исключений) последовательность зачал
  по седмицам от Пасхи опубликована как общественное достояние (например,
  дореволюционный «Указатель церковных чтений» В. Гречулевича) — её можно
  постепенно собрать через веб-поиск, но это не учитывает праздничные и
  святые чтения, которые в реальном уставе часто заменяют рядовые.

Поэтому наполнение `readings_calendar.json` полными и точными данными на
2026/2027 литургический год — отдельный этап, требующий либо загруженного
пользователем источника (скан/PDF/текст «Богослужебных указаний» или
приложения к богослужебному Евангелию/Апостолу), либо кропотливой сборки
через поиск с проверкой каждой записи.

## Использование (после наполнения данных)

```bash
python main.py                # чтения на сегодня
python main.py 2026-09-14     # чтения на конкретную дату
```
