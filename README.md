# Литургические чтения

Апостол и Евангелие на каждый день по уставу Русской Православной Церкви —
с текстом Синодального перевода прямо на странице.

**Сайт:** https://liturgical-readings.vercel.app

По дате приложение определяет, какие чтения положены в этот день на утрене,
литургии, часах и вечерне: рядовые по седмицам от Пасхи и Пятидесятницы,
Триодь постную, двунадесятые и великие праздники, памяти чтимых святых и икон.
Каждое чтение раскрывается полным текстом. Шапка страницы окрашена в цвет
облачения дня.

## Возможности

- **Рядовые чтения на весь год**, включая все отступки и преступки:
  Воздвиженскую (переход к Евангелию от Луки), рождественский период и
  Крещенскую (воскресенья между Богоявлением и Неделей о Закхее).
- **Триодь постная** — от Недели о мытаре и фарисее до Великой Субботы:
  литургийные чтения, паремии 6-го часа и вечерни, родительские субботы,
  12 Евангелий Страстей, Царские часы, 15 паремий Великой Субботы; в будни
  поста — пометка о литургии Преждеосвященных Даров.
- **Неподвижный круг:** двунадесятые и великие праздники, навечерия Рождества
  и Богоявления (с переносом Царских часов на пятницу), особые субботы и
  Недели пред и по Рождестве, Богоявлении и Воздвижении, Неделя праотец,
  86 памятей святых и икон (свт. Николай, свт. Иоанн Златоуст, свт. Григорий
  Богослов, прп. Сергий, прп. Серафим, прп. Амвросий Оптинский, вмч. Димитрий
  Солунский, Предтеча, апостолы, 20 праздников икон Божией Матери — Казанской,
  Владимирской, Иверской, Тихвинской, Смоленской, Почаевской, «Знамение»,
  «Всех скорбящих Радость», «Скоропослушницы», «Достойно есть» и др., Собор
  новомучеников и др.) с правилами сочетания с чтениями дня: бдение, полиелей, малая память,
  чтения «если совершается служба».
- **Минея на каждый день** (`data/menaion.json`, 159 памятей из проекта Ponomar):
  чтения святым, у которых они положены, — мученикам, преподобным, святителям,
  апостолам; местночтимым — с пометкой «если совершается служба». Проверенные
  памяти из `data/feasts.json` главнее; в день бдения или полиелея малые памяти
  не читаются.
- **Перенос чтений:** рядовые чтения будня, занятого праздником, читаются под
  зачало накануне или на следующий день («за среду», «за понедельник»).
- **Воскресные утренние Евангелия** — 11-недельный цикл.
- **Полный текст Библии** (Синодальный перевод, 77 книг): номера стихов,
  курсив переводчиков, киноварный инициал.
- **Цвет облачения дня** — по общему обычаю Русской Церкви.
- Дата по новому и старому стилю, переход по дням, светлая и тёмная тема,
  версия для печати, установка на телефон как приложения.

Чтения рассчитываются для дат **с 14 марта 1900 по 31 декабря 2099 года**
(в этих границах разница стилей — 13 дней).

## Как это устроено

Расчёт идёт в два слоя.

**1. Подвижный круг** (`src/cycle.py`) — положение дня относительно Пасхи:

| Период | Правило |
|---|---|
| Пасха — Пятидесятница | седмицы по Пасхе |
| После Пятидесятницы | Апостол — по счёту седмиц от Пятидесятницы |
| С понедельника после Недели по Воздвижении | Евангелие от Луки с 18-й седмицы (Лк 3:19–22) — Воздвиженская отступка или преступка |
| Отступка до начала Луки | повторяются Евангелия 11-й седмицы (при двух недостающих — 10-й и 11-й) |
| С субботы пред Рождеством (год с отступкой) | Апостол читается по седмице Евангелия |
| Седмицы исчерпаны до Богоявления (ранняя Пасха) | читается 33-я седмица |
| Недели святых отец, по Рождестве, пред Богоявлением | рядовые не читаются |
| После Богоявления | будни — обратным счётом от следующей Пасхи |
| Воскресенья между Неделей по Богоявлении и Закхеем | назад от Закхея: 31-я, 30-я Недели; при трёх воскресеньях перед Закхеем — 17-я (о хананеянке) |
| С Недели о Закхее | Закхей — 32-я Неделя, будни — 33-я седмица |
| Неделя о мытаре — Великая Суббота | Триодь по числу дней до Пасхи |

Пасха берётся из `data/pascha_dates.json`, для остальных лет вычисляется по
юлианской пасхалии с точным переводом в новый стиль.

**2. Неподвижный круг** (`src/readings.py`) накладывается на рядовые чтения
по дате старого стиля: праздник заменяет рядовые или читается вместе с ними
(в воскресенье — чтения Недели и праздника), бдение святого в будни заменяет
рядовые, полиелей читается вместе с ними. Если рядовые вытеснены праздником,
они переносятся на соседний будний день. Не переносятся, как на «Азбуке
веры», чтения навечерия Рождества, Рождества, Обрезания, дня прп. Серафима
Саровского (2/15 января) и Богоявления.

**Цвет облачения** (`src/vestments.py`) — по таблице «Цвета богослужебных
облачений» на azbyka.ru; где допускаются два цвета, берётся первый. Пасха до
отдания — красный; Вознесение, Рождество и Богоявление с попразднствами,
Преображение — белый; Пятидесятница, Вход Господень, преподобные — зелёный;
Богородичные праздники — голубой; Воздвижение, субботы и воскресенья
Великого поста, Великий Четверг — фиолетовый; будни поста — чёрный; памяти
святых — по их чину (поле `vestment` в `data/feasts.json`); остальные дни —
золотой. Местная практика может отличаться — об этом сказано на странице.

## Запуск

Нужен Python 3.12.

```bash
pip install -r requirements.txt
flask --app app run                # сайт на http://127.0.0.1:5000
python main.py                     # чтения на сегодня в терминале
python main.py 2026-09-14 --text   # на дату, с полным текстом
python -m unittest discover tests  # проверки
```

## Структура проекта

```
app.py                  веб-интерфейс (Flask): страница дня, кэширование
main.py                 вывод чтений в терминал
src/
  cycle.py              пасхалия и положение дня в подвижном круге
  readings.py           чтения дня: рядовые, Триодь, праздники, памяти, переносы
  vestments.py          цвет облачения дня
  bible_text.py         разбор ссылки «Мф.4:25-5:12» и текст стихов
data/
  pascha_dates.json     проверенные даты Пасхи
  ordinary_cycle.json   рядовые чтения по седмицам (с номерами зачал)
  triodion.json         Триодь постная: ключ — число дней до Пасхи
  feasts.json           праздники, навечерия, особые дни, памяти (дата ст. ст.)
  menaion.json          чтения святым по Минее (Ponomar, GPL-3.0; дата ст. ст.)
  bible/synodal.json    Синодальный перевод (источник и лицензия — bible/README.md)
public/                 значки сайта (в т. ч. icon-maskable-* для Android) и манифест;
                        на Vercel их отдаёт CDN
tests/                  проверки по контрольным датам и полнота текста
tools/convert_ponomar_bible.py   пересборка synodal.json из исходников Ponomar
tools/convert_ponomar_menaion.py пересборка menaion.json из исходников Ponomar
```

Формат `ordinary_cycle.json`: ключ — номер седмицы, внутри дни `mon`…`sat` и
завершающее седмицу воскресенье `sun`:

```json
{"pentecost_period": {"13": {
  "mon": {"apostle": "2Кор.8:7-15", "apostle_zachalo": 186, "gospel": "Мк.3:6-12", "gospel_zachalo": 11},
  "sun": {"apostle": "1Кор.16:13-24", "apostle_zachalo": 166, "gospel": "Мф.21:33-42", "gospel_zachalo": 87,
          "note": "Неделя 13-я по Пятидесятнице, о злых виноградарях"}
}}}
```

## Источники и проверка

- Рядовые чтения и Триодь сверены построчно с открытыми лекционариями
  [Ponomar](https://github.com/typiconman/ponomar) (русская практика) и
  [orthocal](https://github.com/brianglass/orthocal-python) (номера зачал);
  расхождения в нумерации стихов решены в пользу русской.
- Правила отступок — по «Сказанию» напрестольного Евангелия и статье
  [«О порядке церковных чтений Евангелия»](https://azbyka.ru/o-poryadke-cerkovnyx-chtenij-evangeliya).
- Контрольные даты (2010–2026 гг.) сверены с церковным календарём
  [«Азбуки веры»](https://azbyka.ru/days/) и закреплены в тестах:
  `tests/test_readings.py` — 31 проверка, `tests/test_bible_text.py` — каждая
  ссылка приложения находится в тексте Библии.
- Текст Синодального перевода (1876) — общественное достояние; цифровое
  издание проекта Ponomar распространяется по лицензии GNU GPL 3.0
  (`data/bible/LICENSE-GPL-3.0`).

## Развёртывание

GitHub → Vercel, автодеплой при каждом коммите в `main`. Функция работает во
Франкфурте (`fra1`, `vercel.json`), Python 3.12 (`.python-version`).

Страница дня зависит только от даты, поэтому CDN Vercel хранит её сутки
(браузер — 5 минут), а соседние дни подгружаются заранее: переход по дням
мгновенный. Новый деплой сбрасывает кэш CDN. Корень сайта `/` открывает
«сегодня» по часам читателя.
