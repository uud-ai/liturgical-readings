# Чтения дня (Евангелие и Апостол по зачалам)

Мини-приложение на Python, которое по дате выводит положенные на этот день
евангельское и апостольское зачала согласно богослужебному уставу Русской
Православной Церкви.

## Статус проекта

**Работает, но не на весь год.** Скрипт умеет вычислять дату по подвижному
кругу (от Пасхи и от Пятидесятницы) и подставлять к ней рядовые чтения —
арифметика дат реализована и протестирована. Сама таблица чтений заполнена
частично: см. `data/ordinary_cycle.json`, поле `_coverage`, там честно
перечислено, какие седмицы уже есть, а каких пока нет. Собирается постепенно
через веб-поиск (без праздничных/святых исключений — только рядовой круг).

## Идея устройства

Богослужебный год чтений построен не по гражданским датам, а по седмицам
(неделям), отсчитываемым от Пасхи и от Пятидесятницы, плюс отдельный слой
неподвижных (непереходящих) праздничных и святых чтений, привязанных к
числам месяца — этот слой пока сознательно не реализован (см. ниже).

Реализованная логика:

1. Дата Пасхи по году — не вычисляем сами, берём из проверенного источника
   (`data/pascha_dates.json`).
2. От неё простой арифметикой (`src/cycle.py`) получаем «седмицу N, день
   недели» — Пятидесятница = Пасха+49 дней, Неделя N по Пятидесятнице =
   Пятидесятница+7N дней, и т.п.
3. По этой паре (седмица, день) ищем запись в `data/ordinary_cycle.json`
   (рядовые чтения — таблица, а не вычисление).
4. Праздничные/святые исключения (двунадесятые праздники, памяти святых
   с особыми чтениями, попразднства, отступки/преступки) — **не
   реализованы**. Это самая сложная часть устава, сознательно оставлена
   вне MVP по вашему решению работать только с рядовым кругом.

## Структура данных

```
data/
  pascha_dates.json       # известные даты Пасхи по годам (не вычисляем сами)
  ordinary_cycle.json     # рядовые чтения по седмицам (от Пасхи / Пятидесятницы)
  gospel_zachala.json     # отдельные проверенные тексты-примеры зачал
  apostle_zachala.json    # отдельные проверенные тексты-примеры зачал
src/
  cycle.py                # дата -> позиция в подвижном круге (седмица, день)
  readings.py             # позиция в круге -> чтение дня
main.py                   # CLI: python main.py [ГГГГ-ММ-ДД]
```

### `gospel_zachala.json`

Евангелие имеет отдельный счёт зачал для каждого евангелиста:
Мф. — 1–116, Мк. — 1–71, Лк. — 1–114, Ин. — 1–67.

```json
{
  "Мф": {
    "116": {"ref": "Мф. 28:16–20", "text": "..."}
  }
}
```

### `apostle_zachala.json`

Апостол (Деяния и все Послания) имеет один сквозной счёт зачал, всего 335.

```json
{
  "1": {"ref": "Деян. 1:1–8", "book": "Деяния", "text": "..."}
}
```

### `ordinary_cycle.json`

```json
{
  "pentecost_period": {
    "13": {
      "mon": {"apostle": "2Кор.8:7-15", "gospel": "Мк.3:6-12"},
      "sun": {"apostle": "1Кор.16:13-24", "gospel": "Мф.21:33-42", "note": "..."}
    }
  }
}
```

Ключ `N` — это «моя» седмица: блок будних дней (mon..sat) плюс воскресенье
(sun), которым он заканчивается. `gospel_zachalo`/`apostle_zachalo` —
традиционный номер зачала, если он был проверен по классическому указателю
(не для всех записей есть).

## Источники данных

Тексты синодального перевода Евангелия и Апостола — общественное достояние
(перевод 1876 г.), их можно свободно использовать. Сложность не в правах,
а в том, что:

- Полная годовая таблица зачал по датам с учётом всех исключений устава
  публикуется в специализированных изданиях («Богослужебные указания») и на
  нескольких церковных порталах (например, azbyka.ru — раздел «Церковный
  календарь»), но эти сайты закрыты для автоматического скрапинга
  (бот-защита), а домен не входит в список разрешённых для сетевого доступа
  в этой рабочей среде — поэтому их нельзя было обойти скриптом целиком.
- То, что удалось собрать в `ordinary_cycle.json` — результат точечных
  запросов через обычный веб-поиск (см. поле `source`/цитируемые названия
  страниц у части записей), с перепроверкой, где это было можно. Это
  реальный, но неполный и трудоёмкий процесс: полное покрытие всех ~50
  седмиц годового круга потребует ещё многих таких запросов.
- Праздничные и святые чтения (которые в реальном уставе часто заменяют
  рядовые) сознательно не собираются — по вашему решению ограничиться
  рядовым кругом.

## Использование

```bash
python main.py                # чтения на сегодня
python main.py 2026-09-14     # чтения на конкретную дату (ГГГГ-ММ-ДД)
```

Если данных для конкретной седмицы ещё нет, скрипт честно об этом сообщает,
а не выдаёт правдоподобную, но непроверенную ссылку.

## Что делать дальше

Наращивать `data/ordinary_cycle.json` — по одной седмице за раз, через
веб-поиск (шаблон запроса: `Неделя N-я по Пятидесятнице Апостол/Евангелие
зачало`), либо взять за основу загруженный скан/PDF «Богослужебных
указаний», если он найдётся — тогда наполнение станет намного быстрее и
одновременно позволит добавить праздничные/святые исключения, которые сейчас
не реализованы.
